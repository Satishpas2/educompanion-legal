# EduCompanion — legal pages

The privacy policy and data-deletion page for the **EduCompanion** Android app
(`com.educompanion.app`), a learning companion for children in classes 3 to 8.

- [Privacy Policy](https://satishpas2.github.io/educompanion-legal/privacy)
- [Delete your data](https://satishpas2.github.io/educompanion-legal/delete)

These pages are **generated** from the Markdown sources in the application
repository and should not be edited here — an edit made only to the published
copy is how a policy comes to disagree with itself. Regenerate with
`scripts/build-legal-site.sh` and push the result.
